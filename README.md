# SIGMA LOVE — Our Little Universe

A premium, aesthetic romantic web application for couples. Built with React 19, TypeScript, Vite, Tailwind CSS, Express, and SQLite.

## Features

- **Fullscreen Landing Hero**: Couple photo frame, calligraphy title, quote, quick stats, floating hearts particle background.
- **Our Story Timeline**: Interactive relationship milestone timeline with category filtering, add/edit/delete events, and photos.
- **Photo & Video Gallery**: Masonry, Polaroid, Grid, and Slideshow views with file uploads, full-screen lightbox preview, and favorites.
- **Romantic Music Player**: Song playlist with album artwork, upload MP3 audio tracks, global persistent background playback, and vinyl spinning animation.
- **Private Love Notes**: Messaging-style note wall with heart reactions, pinning, and custom emojis.
- **Anniversary Countdown**: Live ticking counter (Days, Hours, Minutes, Seconds) with milestone achievements and fireworks/confetti celebration.
- **Memory Calendar**: Interactive monthly calendar to view and log memories by date.
- **Secret Love Letter**: Interactive wax-sealed envelope with open animation, paper texture, candle glow, and letter editor.
- **Relationship Settings**: Customize couple names, anniversary date, quote, particle intensity, and private password.
- **SQLite Database**: Local `database.sqlite` automatically initialized with seeds.

## Quick Start

### Development Mode
```bash
npm run dev
```

### Production Build
```bash
npm run build
npm start
```
